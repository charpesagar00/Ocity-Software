# Ocity-Software - QR Code Generator

A simple and lightweight Windows desktop application used to create custom QR codes instantly from any URL or web link.

## 🚀 Features
* **Instant Generation:** Convert any link into a clean, scannable QR Code.
* **Simple Interface:** Clean, single-window user interface for quick operations.
* **Portable Executable:** Runs directly as a standalone `.exe` without complex installations.

## 📥 How to Download and Run
1. Go to the **[Releases](https://github.com)** section of this repository.
2. Under the latest version, click on **`QR.Code.exe`** to download the application.
3. Once downloaded, double-click the file to run the app directly on Windows.
